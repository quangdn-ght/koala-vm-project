  What happens when you run create-faceid-vm.sh:

  1. ✓ Validates ISO and preseed files
  2. ✓ Removes existing VM (if present)
  3. ✓ Starts temporary web server for preseed
  4. ✓ Creates VM with specified resources
  5. ✓ Boots Ubuntu installer
  6. ✓ Downloads preseed configuration
  7. ✓ Partitions disk automatically (entire disk)
  8. ✓ Installs base system
  9. ✓ Installs packages
  10. ✓ Configures user account
  11. ✓ Installs bootloader
  12. ✓ Enables serial console
  13. ✓ Reboots automatically
  14. ✓ VM ready to use!

  Duration: ~10-15 minutes
